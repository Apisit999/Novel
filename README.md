# เว็บอ่านนิยาย

## คำสั่ง
- `npm run dev` เปิดเซิร์ฟเวอร์พัฒนา (http://localhost:4321)
- `npm run build` สร้างเว็บสำเร็จรูปไว้ที่ `dist/`
- `npm run check` ตรวจ type และ schema ของเนื้อหา

## เพิ่มนิยาย
1. สร้าง `src/content/novels/<slug>/index.md` (ดูตัวอย่าง `sample-novel`)
2. สร้างตอนที่ `src/content/chapters/<slug>/001.md`, `002.md` ... ชื่อไฟล์คือเลขตอน
3. ใส่ `draft: true` เพื่อซ่อนจากเว็บจริง (ยังเห็นตอน dev)

## ผู้อ่านได้อะไร
โหมดสว่าง/ซีเปีย/มืด, ปรับขนาดและฟอนต์, จำตอนที่อ่านค้าง (เก็บในเบราว์เซอร์), กดลูกศรซ้าย/ขวาเปลี่ยนตอน
